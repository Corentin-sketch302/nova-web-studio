POUR TESTER
Ouvrir index.html dans un navigateur.

POUR ACTIVER LE CONTACT
Dans script.js, remplacer VOTRE-EMAIL@EXEMPLE.COM par votre vraie adresse e-mail professionnelle.
Le formulaire ouvre la messagerie du visiteur : il n'envoie PAS de message automatiquement.

POUR PUBLIER GRATUITEMENT SUR GITHUB PAGES
1. Creer un compte sur https://github.com/
2. Cliquer New repository. Nom : nova-web-studio. Visibilite : Public.
3. Cliquer Add file > Upload files. Glisser index.html, style.css, script.js.
4. Cliquer Commit changes.
5. Settings > Pages > Build and deployment > Deploy from a branch.
6. Branch : main ; Folder : /(root) ; Save.
7. Attendre quelques minutes. L'adresse sera normalement :
   https://VOTRE-PSEUDO.github.io/nova-web-studio/
